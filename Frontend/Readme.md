# VaradShell

A beginner-friendly shell project with a cyberpunk-inspired red Matrix interface.

## Features

- Red and black cyber-themed interface
- Matrix-style animation
- Login screen and terminal dashboard
- C++ source code
- Frontend built with HTML, CSS, and JavaScript
- Python backend integration planned/in progress

## Technologies Used

- C++
- HTML
- CSS
- JavaScript
- Python
